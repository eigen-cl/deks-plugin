# DEKS v0.1.7

DEKS now guides agents to prefer native vector shapes and catalog icons for artwork that must stay
crisp while resizing or animating. SVG is recommended only when it is trusted or sanitized and the
complete editor, preview and export pipeline supports it. The guidance explicitly preserves the
current DEKS Cloud boundary: arbitrary SVG upload is unsupported and must not be bypassed by fetching
or pasting untrusted markup.
